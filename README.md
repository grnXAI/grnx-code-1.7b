# Qwen Coder

Minimal research repository for coding specialization with SFT and GRPO.

## Structure

```text
data/raw/           downloaded source datasets
data/processed/     normalized train/validation data
data/processing/    download, clean, normalize, and split scripts
train/              SFT and GRPO training entrypoints
execution/          generated-code execution and reward logic
eval/               model evaluation
configs/            experiment configuration
checkpoints/        local model checkpoints
```
